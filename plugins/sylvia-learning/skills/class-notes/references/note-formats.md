# 固定笔记格式

这是新建笔记的固定栏目约定，不只是可选写作建议。实际可复制的 Markdown 模板位于 `assets/`，入口文件直接链接各模板；内容深度由分档标准控制。

## 使用规则

1. 新笔记保留下列二级标题、编号及顺序；讲解、案例与练习栏目用三级标题区分单元／章节，四级标题展开知识点、例句或练习，按需重复。先复制适用模板，再填内容。
2. 每个占位符 `{{字段}}` 都要替换；教学内容未知写“尚未提供／待核／本次未涉及”，不得留下占位符或编造事实。
3. 空栏目用一句话说明原因，不能让读者分不清“未讲”还是“漏写”。用户明确要求简化格式时可覆盖本规则。
4. 编辑已有笔记时，用户原格式与本次定点要求优先；不补齐模板而顺手重排全篇。已有题号不重新编号。用户自写笔记即使未套模板也属于正式笔记，不把 A／B 模板作为其进入正式目录的条件。
5. 元信息含课程、可确认的课次／日期、档次及依据、覆盖状态、关联笔记／听写／索引。不臆测身份、课次或日期。

## 单元／章节归属

- **先确定单元归属，再在单元内整理知识点、例句和练习；无法确定的归属明确标“待核”。** A／B 两档都执行，不因 B 档精简而抹去单元边界。
- 先从老师的转场提示、课件／教材目录与已核实笔记建立“来源位置 → 单元／章节 → 主题 → 成稿位置”的对应。保留原 Unit／章节编号和标题；只确认编号、未确认标题时保留编号并标“标题待核”，不编标题。课程归属已确认不代表单元归属也已确认。
- 每个实质性知识点、例句和练习都须可追溯到所属单元。同一单元内的连续内容可共用标题与出处，不必逐句重复标签；案例、术语辨析和复习自问采用相同归属或回链。跨单元比较注明涉及单元，不强塞进其中一个。
- 课程导论、全课学习安排与考核说明单列，不默认计入 Unit 1。材料确实不设单元／章节时，注明“不设单元／章节”，按实际专题组织，不自造编号；这是已知的无单元结构，与归属不明不同。
- 归属不明的内容放入“单元归属待核”小节，保留来源位置、疑点和待核依据；可以列有证据的候选，但不把猜测写成确定归属，也不默认沿用最近出现的单元。继续整理已确定部分，不以待核为由漏掉内容。
- 一课跨多个单元时分别分组；一个单元跨多课时沿用同一原编号／标题，由课程索引串联。仍按授课日期命名课次笔记，不为单元拆分另造同课副本。
- 固定大栏目不变，栏目内保持“单元／章节 → 主题 → 知识点、例句与练习”的从属关系；第三栏可用紧邻例句说明知识点，第四栏展开案例与练习并回链，避免重复全文。同一单元在不同栏目出现时，在原编号与标题后加“知识讲解／案例与练习”等后缀，保持链接锚点唯一。既有笔记只在获授权范围内补归属标记或调整结构，定点答疑不触发全篇重排。

## A 档固定栏目

模板：`assets/note-a.md`。

1. `一、本课主线与学习地图`：一句话主线、本课问题、知识框架和与前后课的联系（有证据时）。
2. `二、材料范围与课堂脉络`：来源清单、版本、覆盖状态；录音时间线或纯文本章节／页码顺序。
3. `三、分主题完整讲解`：按单元／章节展开各主题定义、推理、条件、例外、关系、应用、例句与出处。
4. `四、案例、例题与课堂问答`：按对应单元展开重要案例与练习完整分析、提问和回应、单元作业；全课考核说明另列。
5. `五、重点辨析与术语校订`：易混概念、专业术语、听写纠错；法学材料有法条时列索引。
6. `六、复习自问与参考答案`：按理解与应用组织，答案通常折叠，逐题给依据。
7. `七、教材衔接与补读清单`：已整合／需要读原文／尚未核对待补；给定位和目的。
8. `八、待核问题与修订记录`：来源冲突、不清楚处、后续问题、实质性修订和回链。

## B 档固定栏目

模板：`assets/note-b.md`。

1. `一、本课主线与知识骨架`：一句话主线＋全部实质性主题的简明框架。
2. `二、材料范围与课堂脉络`：同样说明来源和覆盖，只简化表现，不减少事实范围。
3. `三、核心知识与必记条件`：按单元／章节展开定义／结论、必要理由、条件／例外、关键区别、代表例句与出处。
4. `四、代表案例与课堂要求`：按对应单元保留案例与练习的决定性分析步骤、作业；全课考核说明另列，其他例子指向材料。
5. `五、易混点与术语校订`：必要辨析、纠错和法条定位，不扩大为长篇专题。
6. `六、复习自问与参考答案`：简洁但带判断条件，不用关键词堆砌答案。
7. `七、配套阅读与待补内容`：按三种教材状态明确该看哪部分、为什么；未知页码不填。
8. `八、待核问题与修订记录`：保留不确定项、实质性修订与回链。

听写模板的正文按真实时间反复生成段落，不能只填写一个示例段落就交付。中文完整听写任务可使用同一结构，标题按实际语言改写。

课程索引只是现状入口，不是课程分档的第二个配置源；显示档次时注明取自配置或某次临时覆盖。章节复习合并知识点，不覆盖课次原稿，也不冒充一次新的课堂讲授。

## 来源标注与阅读负担

- 在材料表给出来源 ID（如 `R1` 录音、`P1` 课件、`T1` 教材、`N1` 随堂笔记），并链接实际文件。一个 ID 只对应同一材料版本。
- 关键定义、推理、结论和案例后写紧凑定位，例如 `[R1 00:12:10–00:15:42]`、`[P1 PDF 第 8 页／幻灯片 6]`、`[T1 第 2 版，第 3 章，印刷页 45]`。这些仅为语法示例，不可当作真实来源。
- PDF 文件页与印刷页／幻灯片编号不同就分开标；多个录音用文件 ID＋文件内时间。无可靠定位时标“定位待核”。
- 同一来源支持的连续段落可统一标一次，避免逐句脚注影响阅读；来源变化、冲突和推断处不能省。
- 以自然段解释复杂逻辑，用短列表突出条件；只有比较、对应或时间序列确实更清楚时才用表格。不为“详细”重复同一内容。
- 自问默认 5–8 题，可随材料量调整；采用 Markdown 可折叠块，块内留空行。答案与题号逐一对应，给判断过程与定位。

## 输出命名与关联

正式课次笔记统一使用 `课程名_YYYY-MM-DD.md`，例如 `示例课程_2026-09-22.md`。A／B 均适用；批量整理／目录规范化覆盖新旧课次笔记，不再仅约束新增文件。

- 课程名沿用对应课程的规范名称，不自造简称；日期为实际授课日期，年月日补齐两位月／日，以半角下划线连接课程名与日期。
- 依据课表、素材时间和内容核定授课日期；不能把上传、整理或最后修改日期直接当授课日期。归属或日期仍不明时保留待确认，不编造日期或用“未确认”替代日期创建正式文件；其他确定课次继续。
- 同一课次的多段录音、课件和补充材料汇入同一篇笔记，已有对应笔记则增量更新。若同课程同日有独立课次且确需分别成稿，先确认合并还是例外命名，不擅加序号、不覆盖不同课次。
- 批量／目录规范化时，核实旧笔记的角色、课程和授课日期，再将原文件迁移为规范名称，更新双链、Markdown 链接、索引、处理记录和日志；不另造同课副本。保留内容与版式不等于保留旧文件名。已有名称已合规时不改；角色、日期或目标冲突不明时单列待确认。单点答疑／局部改字不扩大成全目录重命名。
- 先判断文件角色：用户自写的随堂记录、提纲、词汇／例句笔记和课后补充属于正式笔记；粗听写、外部考核通知与无内容占位按素材／参考角色处理。用户创建文件或粘贴 ASR 不等于亲自撰写；作者与角色不明时先核实。历史名称不规范也不证明内容尚未整理。
- 自写笔记若是课次主笔记，沿用核定课程、授课日期后规范命名的规则；独立词表、专题提纲等辅助笔记保留已确认名称，不强套同一天的主笔记名。与 AI 成稿同名时先保留各自原件并确认如何并存，不覆盖、自作主张合并或降为素材；归档本身不授权重写正文。
- 此格式限定正式课次笔记；独立听写稿、课程索引和章节复习不与课次笔记共用同一文件名，沿用各自已确认规则，避免互相覆盖。正文标题与栏目仍按模板保留，不必等于文件名。

启用统一课堂目录时，用户自写笔记与五种正式文稿均放在对应课程的“正式课堂笔记”，原录音、粗转写、课件和原始附件放“笔记素材”；实际目录名读取配置。自写笔记嵌入录音时，笔记留在正式目录，附件按实际角色归位并修链。已确定归属的文件不等待成稿验收才归位，未完成状态另记；自写笔记和校订后的完整听写均不与粗 ASR 混淆。`笔记素材/log.md` 是固定管理文件，不是课次笔记或待处理来源。

课次笔记、听写稿、课程索引、章节复习相互链接；未创建的目标写“未建立”，不生成死链接。链接位置由实际文件决定，不把模板中的相对路径当成用户资料路径。
