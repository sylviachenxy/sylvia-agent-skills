# 课程表、素材时间与内容联合推断

默认输入是**未分类、未按课程命名**的素材。归课是 agent 的工作，不应先要求用户重命名、分类或逐个选择课程。自动推断需要可解释的依据，不是按文件时间机械搬运。

## 先读本学期课程表

1. 读取配置中的课程表目录；未配置时在课堂根内定位课程表。核对材料所处学期，不因某文件最后修改日期最新就把旧学期录音套用新课表。
2. 从实际课表提取：课程全名、星期、节次、每节起止时刻、适用周次／单双周、教师（列出时）、调课说明（存在时）。PDF／图片表格要检查实际布局，不能把抽取后挤在一起的文字误读为相邻星期。
3. 周次范围不是公历日期。只有确知教学第 1 周起点和调课校历时才精确判断第几周；不把课表打印日期、学生年级或第一次看到的录音日期当成开学周。缺少周次基准仍可用星期／时间筛候选，并结合内容，不必让全部整理停工。
4. 课程表只作为上下文，保留原目录，不生成它的“课堂笔记”、不移动进某一课程。可在私有状态目录缓存核实过的结构与原文件指纹；原文件变更、学期变化或新调课说明出现时重新核对。学号、个人姓名等身份信息无需进入归课记录。

## 时间证据分别保留，不互相冒充

| 时间线索 | 使用方法与限制 |
| --- | --- |
| 文件系统创建时间（birth time） | 与新建笔记／开始录音可能相关；复制、云同步或重新导出可能变成导入时间。系统不提供就记未知，绝不以 `ctime` 代替。 |
| 文件系统更新时间（mtime） | 可能对应课中编辑、课后补写或转码；仍作为候选线索，但不是确定授课时间。 |
| 音视频内嵌创建时间、录音起止与时长 | 有则检查时区与导出行为。只有确认某时间代表开始／结束时才能由时长推算另一端。 |
| 正文／录音提到的日期、课次、教师与课程名 | 与原材料核对，通常比后来复制文件产生的时间更有解释力；也可能是引用别的课，不断章取义。 |
| 文件名、相邻文件时间、已有目录 | 辅助线索，不是必须具备的输入，也不是单独足以归类的证据。 |

先统一时区，再比较星期、上午／下午／晚间时段和课表的各节课范围。课堂允许中途开始录音、拆成多个文件、提前开始／拖堂和课后保存；按实际证据解释偏移，不靠任意固定分钟窗口排除材料。跨午夜、时区缺失、导出批次全部同时间等异常要降低时间证据的权重。

“今天全部待办”是否纳入某文件，与“该文件可能是哪一天哪门课”是两个问题：不能为了使用时间推断而把旧时间戳的待办从扫描结果丢掉。

## 形成候选，再用内容辨别

1. 根据创建／更新时间及更可靠的录音时间，列出课表中合理的候选课程和课次；创建与更新对应不同课程时都保留候选，不擅自只选其中一个。
2. 阅读随堂原稿、课件标题／页眉、可用粗转写和附件关系；必要时抽听／识别有区分度的片段。归类阶段不要求先把所有录音全文重转，正式成稿阶段仍须完整处理。
3. 看整段教学主题与术语组合、论证／案例类型、老师称呼、自报课程、上下课衔接，而不是单个共享关键词。例如多门法学课都可能讲“法律”“权利”，这些词不能独自决定课程；一段英语引用也不等于英语课。
4. 对照同一时段的关联材料：笔记嵌入某录音、连续录音明确承接同一主题、课件与讲解逐页对应，都可帮助归组。粗转写和其原录音是同一证据来源，不能当成两个独立确认。
5. 有明确课次的既有正式笔记、用户已确认的教师／课程别名可辅助校验；课程 A／B 分档不参与推断重要程度，不因一次归类改写长期配置。

## 行动阈值

- **明确确认**：用户直接指定，或原材料有明确且无冲突的课程自述／课件标识。复用真实课程目录，可正常成稿与归档。
- **充分支持的推断**：课表与时间相符，且内容／附件提供相互吻合的独立支持，没有实质性反证。直接按推断课程处理，记录“推断”及依据，不要求用户逐一确认，也不捏造置信概率。
- **时间弱但内容明确**：例如文件晚上传或课后才保存，主题、教师和对应课件清楚。允许内容依据优先，说明时间偏差；不能强塞给上传时刻的另一门课。
- **有冲突或证据不足**：两个课程均合理、内容跨课、时间与明确课程线索矛盾且无法解释。先补读有用片段；仍不清楚则只对这些素材提出候选和简短问题，保留原位，其他课次继续。

课表为空白的时段不意味着录音无用，也不授权猜测用户没上课；可能补课、讲座、调课或只是延迟保存。若确有正式调课说明，优先采用与该日期相关的新安排，不改写整学期规则。

## 记录与后续纠正

在本课 `course_match` 中记录：`status`（confirmed／inferred／uncertain）、课程候选与采用结论、课表文件／版本／星期节次、所用时间值和时区、时间可靠性解释、内容证据的定位、仍有的冲突。证据是简短说明和定位，不复制完整录音，也不保存无关身份信息。

本轮有强证据的新归类可直接建立对应课程的两个标准子目录；没有证据时不凭泛关键词新造课程文件夹。用户纠正归属后，更新这条课次的记录、相关目录和链接；回退／改移仍按原文件保护规则执行，不隐藏先前推断，也不把一次纠正扩大为整套永久课程映射。

## 核验场景

- 无课程名录音＋课表时段吻合＋明确主题：自动归类。
- 创建时间落在甲课、更新时间落在乙课：结合内容决定，不能只取更新时间。
- 课后统一复制导致全部文件同时间：降低时间权重，用内容、原始录音元数据和附件对应关系。
- 录音跨两个相邻课时：根据课堂内容决定是同课连续段还是两门课混录；混录按可靠边界分别整理，不能整份硬归一课。
- 缺教学周起点：周次适用性待核，但仍可用星期和内容推断课程；不编造学期开始日期。
- 只有课表时间匹配、内容无法辨认：仍是候选，不据此移动唯一原件。
