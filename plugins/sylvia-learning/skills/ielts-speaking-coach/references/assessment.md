# 评估与进展

评价前回看本次实际输入和 attempt。官方四项维度与时间契约见 `ielts-standard.md`；本文件规定本 skill 如何保存证据和作出有限结论。

## 四维证据

每个维度保存 `status`、`evidence_ids` 和 `note`。`status` 是本次样本相对目标的观察：`observed / partial / gap / not_observed`；不是能力永久标签，也不是官方分数。`note` 说明具体优点、缺口和未获得的机会。

- FC：听完整语流并检查组织；区分构思停顿和找语言的停顿，不能只数停顿或按语速排序。没有原始声音时整体标 `not_observed`，文字连贯性可在 note 单独讨论。
- LR：检查词汇是否精确、合适，以及卡词时是否能换说；不用生词数量作为进步指标。
- GRA：检查结构选择是否服务表达、错误是否反复出现；ASR 未核实的句子不能直接判语法错误，口语省略也不自动算病句。
- P：从可听片段判断理解负担和表达信号；文本、自动转写标点、语音识别成功率不能支持发音判断。

每条证据引用实际 attempt ID；同题重做单独一条。原话不确定时写“观察摘要”，不要加引号虚构原句。只有时间点而无可访问音频时，不声称重听过。记录清楚的反例，不能挑一个最佳句子覆盖其他困难。

## 分数与校准

日常反馈默认不用数字；用户需要阶段档位时，只有完整、陌生、无提示、有可听音频且严格计时的 baseline/mock 才填写可选 `band_estimate: [下界, 上界]`。每维都必须附证据和不确定性，脚本不会自动评分或平均成正式 Speaking 分数。

允许“尚不足以估计”，不为满足目标硬给 8。不能将口音像母语、词汇罕见、答题很长、读稿流利、语法单题全对转换成 8 分。官方分数只能来自实际成绩；AI 估计与真人评估分别保留。

在准备报考、首次接近目标或 AI 多次给出高档位时，建议请熟悉 IELTS 标准的真人教师用一份未经修改的完整录音做独立评估。它是校准机会，不是日常训练前置条件；不替用户联系、预约或购买服务，也不把教师反馈说成官方成绩。

## 进步与稳定性

区分三个问题：

1. 本次是否做出目标动作：有提示的成功也有训练价值，但必须标支持等级。
2. 换题、隔天是否仍能独立做到：使用 review item 的无提示复测记录；只读同题范句不算复测。
3. 是否在整套陌生题中稳定接近目标：同时考虑三部分、四维证据及反证。

内部训练政策：至少三次不同日期、跨越至少两周、不同主题的完整无提示严格模考，在四维都持续出现目标表现，才可以讨论“AI 练习环境中的稳定 8 分对齐证据”。如果缺乏可靠音频、某维证据不足或最近表现回落，明确未满足；这不是 IELTS 官方资格条件，也不构成成绩保证。真人校准结论另列，不能覆盖或删除 AI 记录。

脚本只统计符合条件的样本数量、训练日期和复测结果，不自动执行这项专业判断。review 中两次独立成功显示为迁移证据，绝不自动生成 `mastered` 或“稳 8”。

比较前核对题目难度、支持、时长、音频条件与录音完整性。熟悉题上的进步和陌生题上的进步分开；持续两次阶段检查仍卡在同一问题时，改变练习方法或建议外部校准，不只是增加题量。

## 复测队列

一个 review item 对应一项可观察动作，例如“陌生 Part 3 追问中，用理由加例外限定自己的观点”，而非“英语更好”。

- 首次训练后通常安排 1–3 天后复测；一次只创建一至两项。
- `independent_success` 只用于有可听语音、unseen、support:none、cold/transfer，且教练确有证据判断做到了；脚本把下次检查移至该次本地日期后 7 天。
- `supported / needs_work` 保留真实结果，2 天后再试；不要把求助视为道德失败。
- `not_tested` 不更新原 due date，不能因为打开复习台就算完成。
- 某项已不再值得单独复测，可在有理由时标 `retired`；它表示停止排队，不表示掌握。

队列按学习者所在时区生成。用户改时区不会重新解释旧记录的本地日期；日期只指导训练选择，不会创建 Calendar/Reminders 对象。

## 与 Goal、周复盘的证据口径

训练分钟、练习次数 → 行动发生；陌生题独立迁移 → 有限的能力进展；官方成绩 → 正式结果。不能相互替代。阶段回执包含来源、session ID、实际发生时间、条件、基线候选 / 进展及限制。是否采纳为正式 Goal 基线或成果，由对应 owner 和用户决定。
