# A／B 档制作标准

## 三个质量维度

- **全面**：本次材料内的所有实质性主题均有去向；不等于把全学科、全教材或每句闲谈都写入笔记。
- **完整**：每项结论保留理解和运用它所必需的定义、前提、适用条件、例外、限定与上下文；不能把“通常／在某条件下”写成“总是”。
- **详细**：解释的展开层数，包括为什么成立、论证步骤、案例推演、与其他知识的联系和易错点。两档主要在这一维度及辅助材料保留量上不同。

| 维度 | A：完整学习笔记 | B：核心复习笔记 |
| --- | --- | --- |
| 目标 | 在已核验范围内可作为主要学习材料，便于独立重建课堂理解。 | 帮助快速找回知识结构和关键规则，配合教材／原材料补充学习。 |
| 主题覆盖 | 保留全部实质性主题、重要展开和有意义的课堂问答。 | 保留全部实质性主题的骨架，不因篇幅短而整块丢失内容。 |
| 概念与规则 | 定义、背景、成立原因、条件、例外、关系和应用，逐层说明。 | 定义／结论＋必要理由＋适用条件／例外，简洁但可正确使用。 |
| 推理 | 展开关键推理链；说明争议、反论证和老师回应，存在时保留。 | 保留从前提到结论的必要连接，不只有“所以”。复杂展开指回来源。 |
| 案例／例题 | 重要案例完整呈现事实、问题、依据、分析、结论及其边界。 | 保留代表性案例和独特例外；可合并重复例子，须保留规则如何适用。 |
| 老师补充 | 与理解有关的延伸、提问、澄清和明确考试提示归位。 | 保留关键澄清、重要反例、作业和明确考试提示，次要展开指向出处。 |
| 区别与联系 | 展开易混概念、理论关系和跨课联系；必要时用小表。 | 提炼最易混处和决定性区别，避免为排版堆表。 |
| 自问 | 定义、区别、论证和迁移应用；答案给出推理与定位。 | 主线、关键规则、辨析和代表性应用；答案简洁但条件齐全。 |
| 原书关系 | 明示哪些已融入、哪些必须读原文、哪些未核对。 | 明示应搭配阅读的页／章节和目的；未拿到教材则不猜页码。 |
| 英语听写 | 独立完整原语言校订稿。 | 同样独立完整原语言校订稿，不能降级为摘录。 |

准确性、来源可追溯性、不确定性标注和保护原笔记是两档共同底线。不要用固定字数代表达标，也不要靠复制原材料凑 A 档篇幅。

## 单个主题的展开方式

A 档问：是什么 → 为什么／如何推导 → 何时适用 → 哪些例外 → 与谁相关或易混 → 怎样用于本课案例。材料没讲到的部分明确缺失；可加必要解释，但标为整理者补充，不把每个问题都用猜测填满。

B 档问：核心主张是什么 → 必须记住的理由与条件是什么 → 最容易用错在哪里 → 用一个代表性例子怎样判断。只有单纯事实的主题可简短记录，不生造例题或争论。

## 学科适配：换内容，不换固定大纲

- **法学**：概念／规范 → 构成要件／适用范围 → 法律效果 → 例外／争议 → 案例涵摄；保留法条索引，注明课堂所用版本。老师未明说的案例结论标“依据课堂逻辑的推断”。
- **理论／人文**：问题 → 观点 → 理由与论证 → 反驳／限度 → 与其他观点的联系；不把学派立场写成无争议事实。
- **历史**：时间与背景 → 事件／制度 → 成因 → 影响 → 解释或争议；区分事实、因果论证和后世评价。
- **语言**：原词／原句 → 含义与用法 → 语境／搭配 → 例句与易错处；解释和忠实听写分开，保留用户词表的词性缩写。
- **理工／方法**：问题 → 定义／假设 → 公式或方法 → 关键推导 → 示例 → 适用边界与单位检查；B 也不能丢掉公式前提。

## 覆盖验收与教材状态

用“来源位置 → 实质性主题 → 笔记栏目 → 状态”逐项核对。原始讲授顺序与主题重组顺序可以不同，但每项有去向。课堂无相关内容写“本次材料未涉及”，材料本身没拿到写“尚未提供”，没有完成核查写“待核”；三者不混用。

教材状态按具体知识点／章节分别记录：

1. **已整合**：确已读取、核对并融入对应笔记，写明版次和页／章节。
2. **需要读原文**：给出定位与目的，例如细致论证、文学文本体验、习题、原文措辞或考试明确要求。
3. **尚未核对待补**：缺教材、缺页、版次不明或尚未处理；不能写成已覆盖。

自问答案不得超过证据所支持的范围。老师明确强调的内容标“老师明确”，整理者推测的复习价值标“复习建议”，不编造命题偏好。
