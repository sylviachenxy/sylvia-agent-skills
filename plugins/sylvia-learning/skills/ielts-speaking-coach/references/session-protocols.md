# 会话与训练协议

## 模式选择

| 模式 | 入口 | 结束产物 |
| --- | --- | --- |
| `baseline` | 没有可比较的现状证据 | 完整无提示样本或明确的分项样本、首要缺口 |
| `mock` | 检查阶段表现 | 三部分完整表现、条件标签、四维证据 |
| `daily` | 继续练习、给定一段时间 | 到期复测、一个瓶颈、迁移与下次动作 |
| `drill` | 指定 Part / 能力 / 最低版本 | 聚焦训练与新题验证 |
| `recording_review` | 用户给出录音 | 实际可听部分的诊断、原始条件未知项 |

“看看最近进步”读取档案并比较，不制造一次虚拟练习记录。一次真实会话只有一个主模式；其中每个 attempt 单独记录 cold / retry / transfer / drill。

## 日常恢复

读取 `context`，从 due reviews 中选一至两个。到期很多时按影响与最近失败优先，每次适量；不要求用户偿还所有欠练。历史题目、反馈和范句对教练可见，但先不展示给用户。用户要换主题、减量或停止时立即调整。

选择新题时同时检查 prompt ID、题干和语义。换同义词、换人物姓名或再次问同一故事不构成新题。允许复用题目练习，但标 `seen` / `retry`。用户表示过去看过相似题时询问到足以判断，无法确认标 `unknown`。

默认 25 分钟只是一种可调整分配；5 分钟最低版本做一次短回答、一个修正和一个下次验证。每约五次训练或用户要求时做阶段检查；全套模考要预留 11–14 分钟测试时间及额外反馈时间，不能把 5 分钟片段叫完整模考。结合最近两周 Part 覆盖和四维缺口补齐盲区；不要因为 Part 1 最轻松便长期只练 Part 1。

## 基线与模考

开始前内部准备原创 pack，包含三部分问题、Part 2 题卡、与之关联的 Part 3 追问。只按顺序揭示；不先列词汇、范文或教答案结构。练习记录可保存已使用题目，不保存尚未展示的未来冷测答案。

1. 简短说明考官角色和反馈时点，完成非评分语音检查。
2. Part 1：从日常身份、学习、居住或兴趣开始，再切到其他熟悉主题；一次一个问题，允许自然短追问，不变成聊天或纠错课。
3. Part 2：显示 cue card（主题、提示点、一个解释要求），开始 60 秒准备；可做关键词笔记，AI 不补充。之后允许最长 2 分钟独立陈述。未结束前保持安静；时间到可以礼貌结束。短答、停顿或说不下去都如实记录，不替用户续写。
4. Part 3：沿 Part 2 主题提升抽象度，追问原因、比较、变化、影响、例外或权衡。针对用户刚说的观点自然追问，不固定要求赞同某种立场，不把专业知识水平当语言评分。
5. 整套结束后切回教练，可让用户一句自评，再反馈两项最高价值缺口。

严格计时的记录含三个 Part 的实际总时长、Part 2 准备和陈述时长、独立计时来源及已验证的结束信号。校验脚本接受正式时间范围；准备 59–61 秒仅是测量容差，并非官方宽限。短陈述不会自动作废整次测试，但不能假装已展示持续长陈述能力。

`strict_mock` 是条件派生标签：完整 baseline/mock，三部分齐全、全是可听音频、题目陌生、没有教学提示、没有技术中断或重启，计时核实。任一不满足保留实际材料并标 rehearsal / partial；用户要求 strict 不会让条件自动满足。

## 8+ 导向的专项训练

以下是原创教学活动，不是官方题目或加分公式。

| 可观察瓶颈 | 训练动作 | 无提示迁移 |
| --- | --- | --- |
| Part 1 每题只有一句或机械铺长 | 先直接回答，再选一个真实细节或理由；练同一意思的短版与自然扩展版 | 换主题提问，不要求套结构 |
| Part 2 罗列提示点、没有主线 | 从一次真实经历选关键变化，用几个关键词串起事件；先完整说再找断点 | 新题卡，1 分钟准备后长陈述 |
| Part 3 只复述个人经历 | 把个人例子升为一般解释，再问何时不成立；练比较两种情境 | 新议题追问原因、例外或影响 |
| 总在中句找词 | 不许用卡住的词，用已知词换说；之后对照语义是否准确 | 不相关情境中表达同种关系 |
| 复杂句一多就失控 | 从原话选一个意思，试两种自然结构，核对意义和时态 | 新问题即兴使用，不指定句型 |
| 发音清楚但语调平、听者难抓重点 | 在可听原话中调整意群、重音或语调；只改一个信号 | 自发回答新问题，看是否仍能突出意思 |
| 背稿顺、追问就停顿 | 同一经历换角度、加入真实限制，撤除文本 | 未预告的后续问题 |

不要每次从四维各挑一个错误。以损害表达最大、重复出现且当下可练的一至两项为主。语音问题须有音频证据，不凭中国学习者常见错误诊断个人。

### 提示与纠错

先留出完成回答的空间；日常训练中只有沟通完全卡住、用户求助或正在做微练习时才中途修复。顺序通常是表达目的 → 少量关键词 / 部分结构 → 示例。用户需要直接示范时可以给，并准确标记；不强迫两次失败。

教练改法保持用户意思和自然语域。原句已经地道就保留；缺乏事实时让用户自己选择内容，不替其编造人生经历。反馈说明变化如何改善准确性、清晰度或组织；不发一整篇 9 分范文取代练习。

同题重做一两次足够；用陌生平行题判断是否迁移，1–3 天后检查是否还能做到。跟读、背稿、照句型说均为练习证据，不能计为无提示迁移。

### Part 2 原创题卡示例（看过即 seen）

Describe a small change you made to the way you study.

You should say what you changed, why you decided to change it, and what happened afterwards, and explain whether you would recommend this change to someone else.

Part 3 可问：Why do some people keep using a study method even when it does not work well? What might make advice useful for one learner but unhelpful for another?

这组示例用于解释题型。正式基线另外生成题目；兴趣主题不能成为永远不离开的舒适区。

## 录音与跨客户端

只用用户给出的材料；听音与转写对照，区分考官、学习者和教练示范。缺少准备时间、题目陌生度或提示记录时标未知。不能把后期剪接、朗读范文或多次拼接的录音当即兴基线。

用户在另一个客户端练习时，给一个简短 session brief：目标、模式、题型、提示规则、反馈时点；返回可听录音、带条件的回执或转写后再归档。只有用户自报的时长、分数或“做得不错”作为自报背景，不提升严格证据等级。外部客户端无法写本机档案时，不声称已经同步。

## 收尾

口头反馈保持简短：本次一个有效动作、一个首要缺口、一个下一步。详细回执由 Codex 写入复习台，不要求学习者编辑 JSON。

用户中途停止：有真实尝试则归档 `status: partial`，保留当前已完成工作，不追加追问；没有尝试就只结束，不生成能力证据。档案写入失败时保持同一 session ID 恢复，不能用新 ID 重复计数。
