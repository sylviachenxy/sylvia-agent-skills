# CET-SET4 优秀对齐评估与证据规则

## 1. 评估目标

本 rubric 回答三个问题：

1. 本场是否产生了与 CET-SET4“优秀”公开描述一致的可观察证据；
2. 证据来自冷启动、受指导重做、陌生题迁移、AI 互动还是真人搭档检查；
3. 下一次最应该训练或补测什么。

它不复刻正式阅卷，不计算优秀概率，也不提供可与官方成绩互换的总分。

## 2. 观察状态

每个维度只使用：

- `OBSERVED`：本场有直接、足量证据；
- `PARTIALLY_OBSERVED`：出现部分目标行为，但不稳定或有明显限制；
- `NOT_OBSERVED`：本场有合理机会，目标行为没有出现；
- `NOT_ELICITED`：任务没有产生检验机会；
- `INDETERMINATE`：音质、技术、材料或记录不足，无法可靠判断。

`NOT_ELICITED` 与 `INDETERMINATE` 不是负分，也不能改写为已掌握。

## 3. 证据条件

每项观察同时记录：

| 字段 | 可选值 |
| --- | --- |
| attempt | `cold` / `same_task_retry` / `unseen_transfer` |
| support | `none` / `light` / `structured` / `modelled` |
| partner | `ai:<profile>` / `human` / `none` |
| modality | `live_voice` / `recording` / `text_only` |
| timing | `strict` / `approximate` / `unknown` |
| prompt_familiarity | `unseen` / `partly_seen` / `seen` / `unknown` |

支持等级：

- `none`：只获得正式任务提示；
- `light`：重述任务或给一个不含内容的过程提示；
- `structured`：提供问题、关键词骨架或纠错方向；
- `modelled`：提供可模仿的表达、范句或完整示范。

只有同时满足以下条件的证据，才可用于 CET-SET4 口语 Alignment、Stability 或 Excellent-evidence gate：

- attempt 为 `cold` 或 `unseen_transfer`；
- `support:none`；
- modality 为可听的 `live_voice` 或原始 `recording`；
- prompt 陌生度、计时和技术限制已经披露。

`text_only` 永远只算 `non_speaking_practice_evidence`，即使答案是 cold 且无提示，也不能证明口语表现。其他受支持证据只用于说明训练反应和下一步。

`timing:approximate` 可以支持分项观察，但不能单独支持 `demonstrated_once` 或 Stability；`timing:unknown` 的整场 Alignment 最高为 `partial`，baseline candidate 为 `no`。明显超出正式时限的内容不能用来证明相应限时能力。

## 4. 官方“优秀”结果对齐

### A. 熟悉话题交流顺畅，少有实质障碍

观察：

- 能持续理解对方并作相关回应；
- 能主动发起、跟进和推动共同任务，而非只回答 yes / no；
- 遇到不同意见、短答或轻微误解时仍能维持交流；
- 沟通困难没有反复阻断任务。

### B. 有条理地表达个人意见

观察：

- 观点明确，理由、细节、例子或比较与观点相关；
- 组织和连接使听者能跟上，而非堆叠模板连接词；
- 能在规定时长内形成相对完整的展开和收束；
- 找词和自我修正没有频繁破坏连贯性。

### C. 清楚、流畅地叙述或描述常见事件与现象

观察：

- 人物、事件、顺序、因果或特点表达清楚；
- 关键内容可理解，语音和语言错误不持续妨碍理解；
- 话语能连续推进，停顿、重复和重启不过度；
- 内容具体到足以完成描述，而不是空泛套话。

三个结果都要由相应任务产生证据。单独背熟自我介绍、朗读顺利或个人陈述说满一分钟，不能代替交谈证据。

## 5. 官方人工评分构念的练习观察

以下是对官方构念的练习型操作化。不要给虚假小数分，也不要把各项机械相加。

| 官方构念 | 高水平可观察行为 | 常见反证 |
| --- | --- | --- |
| 准确性和范围 | 语音、语法和词汇大体准确；表达有一定丰富度与结构变化；母语口音不影响理解 | 重复错误改变意思；为复杂而复杂；关键词不可理解 |
| 话语长短和连贯性 | 对整场有足量贡献；能形成较长而连贯的话语；偶尔停顿不影响交际 | 主要是碎片或极短话轮；频繁长停顿；机械背诵但答非所问 |
| 灵活性和适切性 | 能应对话题、角色和立场变化；积极参与；语言符合语境、功能和目的 | 只会一个模板；忽略搭档发言；表达虽高级但不适合任务 |

若用户明确要求看官方 1–5 锚点，可以指出“更接近公开 5 档 / 4 档描述”，但必须：

- 附直接证据和限制；
- 称为 non-official practice anchor；
- 不相加、不转换为等级或概率；
- 不声称与当次标准样本校准一致。

## 6. 朗读练习观察

| 官方构念 | 观察问题 |
| --- | --- |
| 准确性 | 意群停顿是否合理；关键语音、重音和语调是否支持理解 |
| 流利度 | 是否有大量不必要停顿、重复或自我更正；节奏是否大体稳定 |
| 完整性 | 是否漏词、跳行、替换关键内容或未在时限内读完 |

只有原始音频能充分支持这些判断。ASR 转写、用户自述或纯文字朗读不能复刻正式机评；不要输出“机评 4/5”等伪结果。

## 7. 互动能力的训练型证据

互动是对“积极参与、灵活和适切”的进一步观察，不是官方新增评分项。

| 维度 | 可观察行为 |
| --- | --- |
| 话题管理 | 开启任务、维持相关性、推进取舍、总结决定 |
| 互动式倾听 | 明确回应对方刚才的内容，而非等待自己的独白 |
| 话轮管理 | 自然取得、保持、让出和重新取得话轮 |
| 立场协商 | 同意、部分同意、礼貌不同意，并给理由或替代方案 |
| 故障修复 | 请求澄清、确认理解、改述或纠正误解 |
| 任务适切性 | 理解角色、约束和共同产出，在时限内完成任务 |

不能仅凭“说得多”判断互动好。若 Candidate B 代替用户推进或过度合作，应降低该场证据置信度，而不是奖励用户。

## 8. 证据强度

使用两个独立字段：

### Alignment

- `demonstrated_once`：一套完整、未见、无提示且严格按正式时限执行的 mock 中出现主要目标证据；
- `partial`：只出现部分结果，或表现不稳定；
- `not_demonstrated`：任务提供了机会，但关键结果没有出现；
- `indeterminate`：条件不足，无法可靠结论。

### Stability

- `single_observation`：仅一场独立证据；
- `repeated_ai_consistent`：至少两套不同日期的完整 strict mock、多个未见话题和至少两种 AI 画像中反复出现；
- `human_partner_observed`：在前述基础上，严格计时的真人陌生搭档任务也出现相符证据，且每个话轮能可靠归属说话人。

不要把 `same_task_retry` 用于提升 Stability。一次表现可以是很好的起点，但不能叫“已经稳定”。

普通真人搭档不是评分员。只有 Codex 实际听到实时会话或原始录音，并能通过可区分声线或明确 speaker labels 可靠归属话轮，才可使用 `human_partner_observed`；否则相关个人维度标 `INDETERMINATE`。单纯用户 / 搭档自报标为 `human_partner_self_report`，不提升 Stability。第三方结构化观察只能按其具体证据与方法说明，不得写成 rater-calibrated。

## 9. Excellent-evidence gate

以下是本 skill 为“优秀”目标设置的内部训练准出政策，不是教育部考试院的官方判定规则。

可以说“已形成稳定的优秀对齐证据”，仅当：

1. 三条官方“优秀”能力结果都在多套未见、无提示、可听语音任务中出现；
2. 人工三构念和朗读三构念没有持续性的关键反证；
3. 互动在至少两种不同 AI 画像中保持任务完成、回应和协商；
4. 至少包含两套不同日期、不同话题的完整 strict mock，不以未知计时或明显超时的表现替代；
5. 至少有一次严格计时、可听且能可靠归属话轮的真人搭档检查；最好按训练政策完成中期和考前两次；
6. 技术、题目陌生度和计时限制已经披露。

即使通过此 gate，仍只能说“稳定对齐证据”，不能说“正式考试一定优秀”。官方电子成绩报告显示“优秀”才是 Goal 的最终达成证据。

## 10. Baseline candidate

回执中的建议值：

- `yes`：完整、未见、无提示、语音可听且 `timing:strict` 的 baseline / strict mock；
- `limited`：覆盖不全、计时近似、无可回放录音或存在可说明限制，但仍能影响近期训练决策；
- `no`：文字输入、计时未知、已见题、获得结构化 / 示范支持、技术严重中断，或只有同题重做。

`goal-planner` 决定是否采纳、怎样描述可比性和局限。本 skill 不写 Goal 文档，不自行分配 Goal ID。

## 11. 证据引用规则

- 有录音：优先用 `mm:ss` 时间点加不超过一句的短转述；必要时附极短原话。
- 只有实时 Voice：标为 `coach_live_observation`，不要伪造时间点或逐字稿。
- 有转写：先核对音频；无法核对时标 `asr_unverified`。
- 技术故障：写明影响了哪个任务、持续多久、是否重启。
- 没有发生的行为不编造；没有机会观察的维度用 `NOT_ELICITED`。
- 轻微、不影响理解的母语口音不列为核心缺口。

## 12. 阶段反馈

正式评估后只选：

- 一至两项最可靠优势；
- 一至两项最高优先级缺口；
- 一个同题练习动作；
- 一个未见迁移任务；
- 下一次复测条件。

比较进步时引用两次原始、可比较证据。投入时长、练习次数或被 AI 表扬次数都不是能力提升本身。
