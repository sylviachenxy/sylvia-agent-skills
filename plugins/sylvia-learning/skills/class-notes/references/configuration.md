# 独立课程配置

通用制作规则随技能分发；课程名单与个人偏好保存在技能包外。空课程配置有效，不要求先完成每门课分类。不得把真实课程路径、录音或教材复制进技能包。

## 定位与优先级

1. 用户当次明确指定的配置文件优先。
2. 否则读取 `$CODEX_HOME/class-notes/config.toml`；环境变量未设置时读取用户目录下 `.codex/class-notes/config.toml`。这里只定位标准配置，不重新赋值这些环境变量。
3. 不存在时使用以下缺省值，不为创建配置阻塞本次整理。

生效顺序：当次明确要求与适用的已有约定 → 已确认匹配的课程配置 → 全局默认。用户原笔记格式优先于新建模板。单次使用某档不等于永久保存该课程分类。

## 配置格式

```toml
schema_version = 1

[defaults]
fallback_tier = "A"
note_language = "zh-CN"
delivery = "task-artifacts"
review_answers = "collapsed"

[courses]
```

这就是有效的初始配置。相同的空模板位于 `assets/config.example.toml`。只有用户要求创建／修改配置时才复制或编辑，不往已存在配置上覆盖模板。

| 全局字段 | 含义 |
| --- | --- |
| `schema_version` | 当前整数 `1`。 |
| `defaults.fallback_tier` | `A` 或 `B`；未分类时临时采用，不暗示所有课同等重要。 |
| `defaults.note_language` | 新笔记的解释语言，默认 `zh-CN`；不改变听写原语言。 |
| `defaults.delivery` | `task-artifacts`：独立任务交付；`course-directory`：有目标课程目录与对应写入授权时保存。 |
| `defaults.review_answers` | `collapsed` 折叠或 `inline` 直接展示；不改变答案质量。 |

课程用稳定 ID，以下只是说明格式的虚构例子，不得自动写入用户配置：

```toml
[courses.example-course]
name = "示例课程"
aliases = ["示例简称"]
tier = "B"
kind = "english"
note_language = "zh-CN"
delivery = "task-artifacts"
review_answers = "collapsed"
```

除 `name` 外，其他课程字段均可省略；尚未分档就省略 `tier`，不是新增“待定”档。

- `kind`：`english` 或 `general`，省略时根据确切上下文判断。英文教材不自动等于英语语言课；用户明确要英文完整听写时，无论学科都照办。
- `tier`、`note_language`、`delivery`、`review_answers`：覆盖相应全局默认。
- `notes_dir`：可选的实际目标目录；只有在授权范围内才使用。路径不是 shell 命令，不执行其中的表达式。
- `exam_format`：可选的已确认考核方式，未知省略，不推测开闭卷或考试范围。
- `textbook_paths`：可选教材路径数组，表示可用来源，不表示已核对全书。
- `folder`：可选的课程目录名，位于 `storage.class_root` 之下；只是目录映射，不隐含 A／B 档次。已存在的明确课程目录可直接复用，不要求预填所有条目。

固定 A／B 格式无需再增加一项课程配置。英语有录音时的完整听写义务不能被 `tier` 或 `note_language` 意外关闭；用户当次明确缩小任务范围仍优先。

## 课堂根目录与统一归档

在 schema 1 中增加可选 `[storage]`，旧配置不必迁移。只有用户确认课堂根目录及归档规则后，才填写真实路径，并将 `defaults.delivery` 改为 `course-directory`。配置在技能包外，不把私有路径写进分发文件。

| 字段 | 含义与默认值 |
| --- | --- |
| `storage.class_root` | 用户确认的课堂总目录；省略时不自动全盘寻找素材。 |
| `storage.materials_subdir` | 每门课的素材子目录名，默认 `笔记素材`。 |
| `storage.notes_subdir` | 每门课的正式产物子目录名，默认 `正式课堂笔记`。 |
| `storage.archive_materials` | 默认 `false`；明确启用统一归档时设为 `true`。在已授权整理中，归属确定即可归位，独立保留内容待办；不是定时监控，不因仅修改技能就移动资料。 |
| `storage.batch_selection` | 当前支持 `all-pending`：日常批量请求处理全部未完成素材，不拿修改时间当授课日期。用户当次明确的日期限制优先。 |

两个子目录名必须不同、非隐藏且为单个目录名，不能含父路径跳转。内部处理记录固定放在 `<class_root>/.class-notes/processing.json`，首次真正整理时建立，不打包、不当素材扫描。课程分档可继续为空。

启用后，默认路径分别为 `<class_root>/<course-folder>/<notes_subdir>/` 和 `<class_root>/<course-folder>/<materials_subdir>/`。全目录规范化覆盖所有已确认课程，不要求已有可成稿课次。完整听写稿是正式产物；原录音、粗 ASR、课件、随堂原稿和考核说明属于素材。每课素材目录有管理用 `log.md`，从统一处理记录生成，不作为第二份课程配置。配置中已有 `notes_dir` 若与这套规则冲突，先核对现有明确约定，不悄悄改写。

扫描器使用标准库和 Python 3.11+，`--config` 指定配置、`--root` 可临时指定本次已授权根目录；后者只影响只读扫描，不持久改配置。旧 schema 1 的无目录配置仍有效，只是不能无目标地运行批量扫描。

## 课程表与智能归课

可选 `[matching]` 与课程分档无关；用户素材通常未分类、文件名不含课程名时，课程表＋时间＋内容联合推断是默认工作方式，不要求每个文件有命名规则。

| 字段 | 含义 |
| --- | --- |
| `matching.schedule_dir` | 课程表目录，相对课堂根的路径；以用户实际目录为准，不允许跳出课堂根。目录中的文件作为归课上下文，不是待生成笔记的课次素材。 |
| `matching.timezone` | 已确认的 IANA 时区，用于解释文件时间与课表时刻；未设置时扫描器只提供 UTC 时间，不猜用户所在地。 |
| `matching.semester_week1_start` | 可选的教学第 1 周起始日期，仅在有校历或用户明确依据时填写；不知道就省略，不根据打印日期推算。 |

未设置 `schedule_dir` 时，在课堂根内查找实际课程表目录并读取；多学期或多个冲突版本时按材料时间与课表标记核对，必要时确认。课表文件变化后重读，不一直沿用旧解析。课表中的学生身份、学号等不写入技能源文件或归类依据。

扫描器只提供带时区的文件系统创建／更新时间，不自动解析课表或作语义分类；在系统不提供真实创建时间时返回空值，不能拿 Unix `ctime` 当创建时间。录音内嵌时间、材料正文与课表由 agent 按联合推断规则核实。

## 匹配、修改与安全

- 用 TOML 解析器（如 Python 3.11+ 的 `tomllib`）读取，不作为脚本执行。
- 按用户明确 ID、课程名称、别名匹配，结合给定材料路径确认。多个匹配时不擅自选择目录；先完成不受歧义影响的工作，需要决定保存目标时再问。
- 配置无效时指出具体字段，不静默重写。能依当前要求完成的工作继续，并说明错误配置未生效。
- 只有用户明确说“以后这门课都按……”或要求维护配置时持久保存；保留其他课程、注释和用户设置。索引仅展示结果，不另建一套不同配置。
- `notes_dir` 的存在不等于授权重写整个目录；既有明确写入授权持续适用，不重复询问。没有目标时交付独立文件，不先要求全部课程建档。

## 核验例

- 空课程＋未指定：临时 A，课程配置仍为空。
- 空课程＋当次 B：使用 B，不增加课程条目。
- 长期 B＋当次 A：本次 A，长期 B 不变。
- 英语 B＋录音：B 笔记和完整原语言稿分别交付。
- 只要求回答一个复习题：回答该题，不创建新目录或写回配置。
- 已配置课堂根目录＋“整理今天所有课堂笔记”：检查全部待办和课程目录，已确定素材归位，按课成稿验收并分别更新状态／日志；不要求每次重复给路径。
- 只有目录配置、用户本次要求“完善 skill”：仅修改技能／配置及运行合成测试，不处理真实录音、不移动课堂文件。
- 匿名录音＋本学期课表：先形成时段候选，再用内容和附件核对；充分时直接归课，有冲突时不硬移。
