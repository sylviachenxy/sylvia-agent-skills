# 诊断、教学与可验证进步

## 诊断的深度按问题决定

单题不做全套访谈。持续备考先采集目标届别、当前学校训练材料与最近可信成绩，再用短任务采样。无完整试卷时，可以在约 20–30 分钟内做语境词义、句法解释、短阅读证据、翻译／概要或短写作中的几项；这是本 skill 的起步方案，不是官方诊断工具，不由其推总分。

每项标出条件：材料来源与页／题号、是否未见、可用工具、是否计时、实际音频、提示等级。未测能力保持 unknown；不因大学身份、学校、一次高分或自信就跳过基线。分不清语言知识缺口还是审题问题时，用一个更小的对照题辨别，不先给永久标签。

学生已经提供答案时属于接收历史样本，不伪造“展示前已冻结”。可用其诊断并说明 answer exposure；从后续新题开始运行 prepare/present 的完整流程。

## 先检题，再考学生

教师侧在学生看到题目之前准备题干、可接受答案、必要推理依据和 rubric。原创题明确标原创；核查自然表达、上下文充分性、单选唯一性、替代答案和干扰项可排除性。生成出题后再独立解一遍，不因最初设定答案就认定题目无误。

题目被证实多解或材料缺损时停评分，承认题目问题；不通过追加原题没有的前提维护答案。修订题须新 item ID，已看内容仍算曝光。真题只保存必要定位，整卷与录音留在用户授权的本地位置；不绕过登录、付费或访问限制，不承诺所有考题均无版权。

本包 START-SUMMARY-02 扩展自开发测试稿 START-SUMMARY-01，主干情节和答案要点相同；见过旧题或答案的学生须 prior_exposure=true，不能将它用于新的独立掌握证据。需要独立复测时换真正的新材料。

`source.kind` 表示题目出处，`answer_status` 表示当前核验层次。tutor_checked 不等于 official_key_verified；“网上有人说是上海卷”不能升级为官方。

## 提示阶梯

| support | 教师动作 | 证据意义 |
| --- | --- | --- |
| none | 等待真实作答；不额外给线索 | 条件满足时可用于独立证据 |
| location | 指出需复查的句子／结构位置 | 已有帮助 |
| cue | 提醒对比、关系或关键问题 | 已有帮助 |
| rule | 短讲规则，并用不同例子演示 | 知识教学 |
| model | 展示局部或完整解法／范文 | 答案曝光，不用于掌握认证 |

用最低足够帮助。基础全无、明显疲劳、时间很短或用户直接要解释时，可以早点讲；提示协议不是惩罚仪式。能用一个关键例子讲清就不连讲十个术语。teach-back 可以检验理解，不能替代实际解题或真实音频产出。

训练与模考两种状态分开：训练允许停下、重听和提示；严格模拟按已核验规程完整执行，期间不纠错。改变条件后立即标成 rehearsal，不追认严格成绩。

## 错因到下一题

建议稳定分类：task-reading、sense、collocation、morphology、syntax、reference、discourse-logic、inference、content-selection、organisation、register、pronunciation、listening-perception、time-management。分类是教师诊断，不是机器事实；可有多个，但只优先解决一两个最早断点。

例如：阅读选错先检查是否把原文的“部分”看成“所有”，不是立刻补全部生词。翻译词都认识但关系错，先处理逻辑主体和时态，再处理措辞。写作跑题先纠任务，不先润色句子。

反馈包括：一条具体已做对的证据、一个主要差距、下一次可观察标准。学生自评与教师观察分别记录；AI 范文和转述不计学生产出。

## 独立性与曝光

脚本要求先 prepare、再 present，最后 record。任何已见同题（包括同题改 ID、重复空白／大小写）不会重新得到 unseen；提示后的重做也不计独立。来自别处的曝光由教师向学生核实并标 prior_exposure，未知按 true 处理。脚本只检测文字指纹，不能识别所有语义近似题：只换人名或数字的同构背诵题，由教师标已见／非迁移。

完整答案、关键词答案、范文、纠错后的重写都属于影响独立性的帮助。先展示了再录入的材料不得伪装为未见。`new_context` 必须解释任务中真正变化的语境、体裁、关系或干扰；不是随手勾选“迁移”。

## 状态与复测（本项目约定，非官方量表）

状态按 domain + focus + demand 分开；`grammar:relative-reference / understand` 与同一点的 produce 不互相替代。词汇 focus 带词条及义项，如 `vocab:charge:request-payment`，不要只叫 vocabulary。

| 状态 | 可观察证据 | 默认复测间隔 |
| --- | --- | ---: |
| exposed | 接触了材料，尚无足够评估 | 1 天 |
| needs_work | 最新评估未通过或仅部分满足 | 1 天 |
| guided | 有帮助／已曝光条件下完成；未独立通过 | 1 天 |
| independent | 未见题首次回答、无提示，达到预设标准 | 3 天 |
| transferable | 在已有独立证据后，于另一真实新语境再独立通过 | 7 天 |
| durable | 两次独立通过间隔至少 7 天，后一次是真正新语境 | 21 天 |

没有样本为 unknown，不强建“零分”。这是 first cut 的保守调度规则，不叫 SM-2/FSRS，也不声称为每个学生最优。新的失败／部分通过会退回 needs_work，指导完成不掩盖尚未解决的错误。重做或未评分记录不推迟原本的独立复测。教师可根据考试临近和用户容量优先选题，但不能篡改证据日期“清空逾期”。

对产出型任务，pass 必须是与当前微目标匹配的充分表现；不能因整篇作文中出现一个好句就将所有写作能力标 independent。脚本计算条件，教师仍负责 rubric 是否适当、证据是否真实、判定是否有依据。durable 也不是永久掌握或考试保证。

## 每次收尾

保存真实回答或用户批准的观察摘要、条件、判断依据、错因和一个下一步。回读 context 看状态、复测日、证据 ID。说清本次完成了什么、尚未测什么，不自动把配置、计划时间、题量当学习成果。没有工具权限时在对话给简短回执，并明确尚未持久化。
