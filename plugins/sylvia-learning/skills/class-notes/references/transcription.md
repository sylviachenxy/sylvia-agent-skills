# 录音听写与校订

覆盖已提供录音中的完整可辨语音，并区分实际内容、识别推测与后加解释。英语课的听写精度和覆盖标准不随 A／B 改变。除非用户明确缩小范围，不能把完整稿缩为教学摘要。

## 准备与工具选择

1. 从文件或笔记嵌入定位原录音，检查可读性、时长、声道、语言和损坏情况。多个文件分别登记，不凭文件名断言连续。
2. 同一录音已有校订稿时先核对文件身份、处理范围和可靠性，可复用经确认部分，针对缺段和错误复核。
3. 检查实际可用的本地音频工具与能力再选择识别方法。新的外部服务、收费、上传录音须有相应授权；不为方便将本地音频发送到未获授权服务。
4. 粗 ASR 只作参考，有原音频就回到原音频核验。只有文字时可语境修订，但标“未对原音频核验”；不能称为重新听写。

若使用 `mlx-whisper`，先定位并检查环境中的 `mlx_whisper --help`、音频解码依赖和语言参数；不假定 `python -m mlx_whisper` 可运行。不写死某台机器的虚拟环境路径，不自动下载大模型或安装付费服务。环境未提供的工具不能假装调用成功。

## 转录与时间处理

- 使用原语言转录，不用翻译任务代替听写。英语课保留中文讲解及中英文切换；混合语言识别失败时按段调整，不强迫整段英语化。
- 长录音分段保留少量重叠和真实文件时间偏移；拼接去除机器生成的重复，保留真实讲话的重复、自我修正和问答。
- 术语提示来自可信课程材料，但提示词不能替代声学证据。不能把课件整句补进没听见的录音。
- 保存原始 ASR 与带时间的分段输出，校订稿另存；记录识别方法、语言策略、覆盖范围与实际复核方式。

## 完整性和疑难复核

1. 检查进程退出状态、输出非空、段数和文本长度合理；起止时间覆盖音频，同时检查内部缺口。最后时间戳对齐不代表中段没有漏听。
2. 对照静音、杂音、休息和真实讲话区间，核查开头、结尾、长空白、重复幻觉和不合理语言变化。缺失的语音段补转录并记录。
3. 优先核对专名、专业词、数字、否定词、法律／技术规则、推理关键句和学生提问。课件与教材可辅助确认，不得据此伪造讲话。
4. 使用实际可用的音频回听／理解能力复核疑难处；只运行另一轮 ASR 不等于逐字听核。没有音频感知能力时如实说明，只交可达到状态的稿件。
5. 无法可靠辨认时在原位置写 `[听不清 00:12:35–00:12:42]`，必要时另列候选与原因。确认纯噪声写 `[杂音]`，不能给噪声编文字。
6. 按真实状态写“自动识别稿／校订稿／部分完成”，同时说明复核方法、未覆盖区间和待核项。不能承诺零错误或把粗稿标为精准成稿。

## 忠实完整稿

- 使用固定听写模板，列原录音链接、时长、时间范围和完成程度；正文按话题或自然段标真实时间。
- 多录音标“文件 ID＋文件内时间”；累计时间仅在确已换算时另注明，不伪造精确时间。
- 保留原语言、语序、口语语法、可辨的重复与自我修正，允许补标点与段落。老师语法或知识性口误保留原话，校订说明另列，不悄悄改为正确句子。
- 可确认时用“老师／学生”或稳定说话人编号；无法确认就不虚构身份或姓名。
- 完整稿不无声跳过可辨对话；离题语音可标为闲谈但保留。静音、休息、不可辨声和缺失语音分别标记，摘要不能代替正文。
- 术语纠错只改有依据的识别错误；“老师确实这样说”与“机器识别错了”必须区分。拿不准时保留不确定性。
- 英语稿与笔记分别保存并互链，中文解析／翻译不冒充原文。

## 受阻时

先检查可用工具和材料，报告具体限制。继续完成能独立完成的课件／文字整理，听写仍标未完成；不能用课件合成似是而非的文稿，也不能把技术失败当作已完成整课听核。
