# 通用制作约定

这份约定规定长期整理的交付责任，不规定哪门课更重要。已确定的制作要求、可以更改的默认值和仍待配置的信息必须区分。

## 固定制作要求

| 要求 | 执行位置 | 完成判据 |
| --- | --- | --- |
| 不同课程采用不同深度 | 独立配置＋A／B 分档标准 | 不强迫所有课程同档；单次选择不变成永久分类。 |
| 详细但清晰 | 固定格式、主题讲解与对比 | 先主线后细节；解释逻辑，不按录音重复顺序堆字。 |
| 以原始材料为依据 | 来源清单、覆盖清单、定位标注 | 说明实际处理了哪些文件／页／时间段，不拿粗 ASR 代替听核。 |
| 英语课录音自动完整听写 | 听写规则＋独立听写模板 | A／B 均有完整原语言文稿，保留中英文切换与疑点。 |
| 重新听写要纠错 | 原音频复核、术语与纠错栏 | 检查专业词、否定、数字等；无把握处标待核，不猜词填空。 |
| 两档同样可靠 | 分档标准、交付验收 | B 可少展开，但不删掉会改变结论的条件、例外或不确定性。 |
| 教材可以以后补充 | 教材覆盖表、增量整合 | 核对版次／章节，记录哪些已融入、须读原文、尚待核对。 |
| 笔记能支撑理解和复习 | 自问与参考答案、章节复习 | 不只有摘要；问题覆盖概念、区别、推理、应用并能定位答案。 |
| 保留用户原笔记习惯 | 快照、最小补丁、差异检查 | 不擅改原层级、缩写、编号、批注和未涉及文字。 |
| 长期可维护 | 课次笔记、课程索引、章节复习与修订 | 新增材料、问答、纠错可回填定位，不重复制造整套笔记。 |
| 新素材有统一入口，成稿与素材分离 | 目录配置、批量归档流程 | 从课堂根目录主动发现，正式产物和原素材分别进入对应课程的正式／素材子目录。 |
| 正式课次笔记统一命名 | 固定格式、单课与批量成稿流程 | `课程名_YYYY-MM-DD.md`，日期取授课日期，A／B 相同；批量规范化包含已核定日期的旧笔记，保留正文、更新引用，不覆盖冲突目标。 |
| 所有课程目录规范 | 结构审计、按角色归位 | 只有考核说明或空文件的课程也建立两个子目录；素材归位不依赖内容整理是否完成。 |
| 每课有可读处理日志 | 素材目录 `log.md`、统一处理记录 | complete／incomplete／pending 分开；incomplete 必须已经开始并写原因、缺口及下一步；未登记先待核定，日志不再当素材扫描。 |
| 一句话批量整理且可续做 | 只读扫描、来源指纹和处理记录 | 已完成不重复；新文件、内容变更、缺段与失败不漏；不以归档位置代替完成证据。 |
| 不要求用户预先分类或命名 | 学期课表＋素材创建／更新时间＋内容联合推断 | 默认主动推断课程；有充分依据直接归类，冲突或歧义才单独确认，不仅按时钟硬分配。 |
| 共性技能与课程设置分离 | 配置规范、空配置模板 | 课程名单、路径、考核方式不写死到技能中；空配置可工作。 |

## 关于“以后还用不用看书”

- A 档的目标是让**已核验覆盖的范围**可以主要通过笔记学习，而不是保证任何来源条件下都不用看书。只有课堂材料时，不得声称教材已覆盖。
- 教材、课件和录音核对后，仍把需要体验原文、研读论证、做练习、核对争议或考试另有要求的部分单列出来。
- B 档是保留完整知识骨架的核心复习资料，通常需要配合教材或课堂原材料理解。不能默认“平时都不用看，考前再补就一定够”。
- “老师明确说会考／不考”“整理者判断值得复习”“考试范围未知”分开标记，不推销考试覆盖保证。

## 可调整的工作默认值

默认新笔记用中文讲解并保留原术语；采用独立 Markdown 文稿、折叠参考答案；课程尚未分类时临时使用 A。已确认统一课堂目录时直接按配置保存，不再回退成任务目录附件。复习自问通常 5–8 题，按本课实际信息量调整。这些默认值可由用户覆盖，不是已经确认了每门课的永久分档。

新笔记使用固定栏目；用户提供自己的格式或明确要求改变格式时，其要求优先。定点编辑沿用原格式，不为了统一模板重排整页。

## 暂不配置也不阻塞的事项

- 每门课归 A 还是 B，是否按某些课次临时调整。
- 教材书名、版次、文件与具体章节。
- 开卷／闭卷、题型、老师的正式考核范围。
- 尚未确认的课程别名；已经确认的根目录、两个子目录与正式课次笔记命名规则应直接沿用，不反复询问。

先完成可确定的工作；缺失信息只有在会改变具体内容或导致写错文件时才询问。不要在建立通用技能阶段要求一次性回答全部课程配置。

## 任务边界检查例

| 输入情形 | 正确处理 | 不应发生 |
| --- | --- | --- |
| 未配置课程，要求“详细整理” | 临时 A＋固定 A 模板，配置不变 | 自行把课程永久登记为 A。 |
| 英语课指定 B，提供完整录音 | B 笔记＋同等完整的原语言听写稿 | 把听写缩为关键词或中文翻译。 |
| 只有粗转写，要求重新听写 | 定位原音频；没有时标未核音，先做可完成修订 | 声称已回听全部录音。 |
| 询问原自问第 11 题 | 读取确切第 11 题及相关材料后回答 | 猜题、改编号、重做整课。 |
| 仅要求给词汇补音标 | 最小编辑，保留词性、顺序和解释 | 替换用户词表样式。 |
| 后补教材与课堂观点不一致 | 并列出处、解释版次／立场差别与待核项 | 悄悄覆盖老师观点。 |
| 要做章节复习 | 归并同一知识点，比较差异并回链课次 | 简单拼接全部课次，或丢掉原始出处。 |
| 仅练英语口语／安排学习日程 | 不触发本技能的整课整理流程 | 生成课堂笔记替代训练或日程。 |
| “整理今天所有课堂笔记”且已配置根目录 | 结构与内容双扫描，确认归属后归位，逐课成稿、验收、登记日志 | 只扫当天修改文件；跳过正式目录的结构检查；把管理日志当新素材。 |
| 只要求规范整个课堂目录 | 所有已确认课程补齐结构、旧成稿改名、原材料归位，内容状态不变 | 因没有新课跳过课程；因听写失败把确定归属的材料留在根目录。 |
| 素材已归档但尚无合格成稿 | 保留待办；继续核听／补笔记 | 因文件不在根目录就当作已经整理。 |
| 只要求完善这个技能 | 更新规则和已明确的独立配置 | 立刻移动全部真实录音或重排已有笔记。 |
| 素材匿名、散放根目录 | 读本学期课表，结合时间、内容与附件关系归课 | 因无课程名直接要求用户分类；仅按 mtime 归课。 |
