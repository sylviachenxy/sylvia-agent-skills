# 精读能力与习惯评估量表

## 使用规则

只在基线、阶段结束、换书或用户主动要求时使用。分数是描述等级，不是心理测量。每项必须附一条具体证据，并分别记录有引导和独立表现。

等级：

- **0 未出现**：没有证据，或即使完整提示仍无法完成。
- **1 提示后出现**：需要明确模板、示范或纠正。
- **2 基本独立**：在少量提示下稳定完成，偶有边界问题。
- **3 独立迁移**：无模板完成，并能迁移到新材料或延迟提取。

## 能力维度

| 维度 | 观察证据 |
|---|---|
| 核心理解 | 能区分主题、主张、章节功能或叙事变化 |
| 文本锚定 | 使用准确概念、原句、页码、场景或事实 |
| 证据关系 | 能说明依据具体支持什么，不把来源、例子或流行度当证明 |
| 结构与层次 | 并列项同层，能识别上下位、时间、因果、比较等关系 |
| 推理与前提 | 能补足中间机制，识别隐含前提和替代解释 |
| 边界与批判 | 能使用限定条件，提出反例而不制造稻草人 |
| 来源归属 | 区分作者、译者、编者、引文、用户推论和书外补充 |
| 综合与迁移 | 跨章节连接，并用于新例子、现实问题或新书 |
| 元认知 | 能准确说出懂了什么、不懂什么、需要查什么 |
| 独立性 | 能自行决定重点、问题、笔记结构和阅读策略 |
| 延迟保持 | 间隔后能提取核心、证据和关系，而非只认得答案 |

## 习惯维度

| 维度 | 观察证据 |
|---|---|
| 触发稳定性 | 在约定情境中能较少犹豫地开始 |
| 最低版本可行性 | 状态差时仍可完成最低版本 |
| 负担调节 | 能主动在精读、轻读、泛读、暂停和换书间选择 |
| 恢复能力 | 漏读后能恢复，不补债、不全盘放弃 |
| 持续记录 | 能记录开始、回忆和负担，而不只追求页数 |

## 阶段评估模板

### 结论

- 有引导能力：列出最可靠的两项证据。
- 独立能力：列出最可靠的两项证据。
- 延迟保持：说明间隔多久、能回忆什么。
- 习惯状态：只描述当前行为证据，不宣布“已经养成”。

### 已经稳定的能力

只写在两次以上或一次跨材料迁移中独立出现的能力。

### 仍依赖提示的能力

注明需要哪一级提示，不把修改稿当原始能力。

### 最重要的一个误差模式

选择重复出现、最影响理解的一种，例如过早概括、证据错配、层次混淆或逃避判断。

### 下一阶段

- 能力重点：最多两个。
- 习惯调整：最多一个。
- 脚手架目标：明确从哪一级降到哪一级。
- 验证任务：指定一个新章节、新书或延迟提取任务。

## 禁止的评估做法

- 不用单次修改后的流畅程度推断稳定能力。
- 不把贴近教练示范的答案视为独立生成。
- 不把知识丰富等同于精读能力强。
- 不把阅读速度慢等同于精读能力差。
- 不用频繁小数分数制造精确感。
- 不把连续几天阅读宣称为习惯形成。
