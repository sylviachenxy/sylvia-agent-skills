## 首次形成某届基线

在个人档案 baseline_note 中保留简短核验摘要与本地详细基线文档定位（详细文档由 agent 在获准档案范围内维护，不塞进公共 skill）：

- region=Shanghai、普通高考英语、年份及场次；不要混入中考、三校生、PETS、CET。
- curriculum_version 与版本证据；用户确认的教材版本不自动证明考院适用届别。
- official_rules：每一项规则对应发布机构、标题、URL／用户材料页码、发布与核验日期、适用范围。
- blueprint：已验证的题型、题量、分值、时长、词数／作答限制、听说条件；未知项显式写 unknown。
- paper/key：具体卷别、题目来源和答案来源；试题、官方答案、机构解析与 tutor 判断不混层。
- status：provisional / verified_for_named_session；完整规则未齐时不得升级。

`baseline_note` 是定位摘要而非机器认证。脚本不会验证官方网页或自动批准真实考试基线；这由教练按来源逐项核验。换届别、考试通知更新、用户提供相冲突材料时重新核验，不静默覆盖旧基线。

## 严格模考的入口条件

必须同时有：已核验场次规程、完整且此前未做／未看答案的卷、独立保管的可靠答案／评分标准、可执行计时、所需真实音频及播放次数控制、无提示的执行条件。条件少一项就叫“专项练习／演练／部分诊断”，说明具体缺口；仍可练，不虚称完成严格模考。

不把本包原创起步题拼起来报官方总分。真实学生提交的历史分数记录为 user-reported，能够核对成绩单才另记证据；几道微题或一段文字口语样本不能据以预测 130 分。

本书的教学示例不是某场高考试卷，参考答案也不是官方评分细则。听说设备是否可用须在学生真实客户端验收；本机 Python 测试通过不等于录音、计时或评分已经与正式考试等价。
