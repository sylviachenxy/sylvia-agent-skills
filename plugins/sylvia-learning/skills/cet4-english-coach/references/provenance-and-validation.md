# 来源、实现与验收边界

## 设计来源

- 本仓库上海高考英语教练的循证方法：材料验收、标准与教学推断分开、冷作答／支持／迁移／保持区分、配置和证据持久化。复用的是方法和通用存储机制，不复制高考115＋25＋10评分或140分目标。
- 本仓库原cet4-speaking-partner的口语官方契约、完整会话协议、优秀对齐rubric与回执：迁入本skill，无第二个活动入口。新增统一状态、无音频insufficient、近期反证及30天复核窗；旧回执不自动转换。
- `cet4_store.py`从本仓库`tutor_store.py`的通用存储逻辑改编：独立包内代码，不import其他已装skill；分数和口试索引由新的`assessment.py`实现。部分通用回归随逻辑改编，另加四级专属数值／条件测试及可搬移CLI验收。
- 官方制度、题型和评分依据见exam-and-score-standard及cet-set4-standard；近年题卷来源、哈希和实际验收程度见materials-and-sources及随包目录。原创起步题由本次维护编写，不标为真题、完整基线或经校准题库。

## 自动验证方式

从实际skill目录运行：

```bash
python3 -m unittest discover -s tests -v
python3 scripts/cet4_store.py --help
python3 scripts/cet4_store.py materials
```

测试使用合成学生、临时Vault／registry及受控时间，不操作真实Obsidian、Apple账号或录音。覆盖：

- 710报道分与原始表现隔离、官方249／249／212分项、缺项、不合理总分、布尔／非有限数值拒绝、历史导入与评分更正、假设算术。
- 八类笔试组成、正确数权重、已见材料、答案／音频验收、播放／字幕污染、帮助、技术故障、时间与同一场次门槛。
- 口语实际音频、任务覆盖、双方dry run、计时、逐阶段揭题、不同日／主题／搭档、真人归属、反证、旧证据复核及文字降级。
- 配置CAS／历史、幂等、不可变题目、同题曝光、独立／迁移／保持、数据完整性、管理块／用户笔记保护、写入部分失败恢复、symlink与Git隔离。
- 复制整个skill后在无关cwd、Python `-I` 下建档、跨进程恢复、配置更新、显式迁址、多学习者选择；资源链接及无开发路径依赖。

## 没有验证或交付的内容

没有真实学习者长期成效、考试分数预测校准、真人评分员一致性研究；没有真实Voice／原始音频播放／外部timer端到端UAT；没有报名、Apple写入或手机同步测试；没有完整真题答案／听力逐项验收，整卷冷测准入数仍为0。上次上海教材的权利及完整转写不适用于新的四级资料。

上述记录是构建阶段的本地验收，不代表远端发布或用户正式安装状态。后续经维护者授权的发布、远端SHA与GitHub来源安装验收以仓库CHANGELOG及对应PR记录为准；不会因此自动更新用户正式安装或卸载旧副本。发布授权、Git远端、安装成功、真实教学成效是不同完成条件。
