## 词表规则

- 原书正文的无星、单星、双星分别为必修、选择性必修、选修；附录 3 初中列星号是初中理解／高中达到运用，高中列星号是选择性必修。国家 2020 课标的标记是另一套，不能混用。
- 高学段涵盖低学段。一个词可以在小学是名词、初中添义、高中新增动词义；同一格也可只有某个义项带星号。
- 原书的累计不少于 2,000／3,200 词是教学数量要求，不是导出文件必须恰好 3,200 行。3,319 是所扫描表格的物理词头行数，不是考纲新增词数或可直接用来算掌握率的分母。
- 同形大小写、英美变体、复数括注及组合词头保留；查询别名可能多义，多候选时先辨明，不默认第一条。
- 国家 2020 版 3,000 条词表作为独立国家基线随包提供；不与上海四列表自动相减得“增补 200 词”。后续修订与特定上海届别的衔接需官方证据。

## 默认随安装接入

完整校对转写、结构化词表、来源信息、原书疑点及必要的图像资料属于本 skill，随安装交付。路径由脚本自身位置解析；不依赖开发目录、原始 PDF、网络下载、Vault 或个人配置。原始 OCR 和构建日志不在运行包。

```bash
python3 "<skill-root>/scripts/curriculum_lookup.py"
python3 "<skill-root>/scripts/curriculum_lookup.py" --word "charge"
python3 "<skill-root>/scripts/curriculum_lookup.py" --unit syntax
```

脚本先校验已封存的教学资源 SHA-256，再返回词条或 reference 路径。单元查询不把整书全部塞进 context：用返回文件按标题／原页读取，同时读该文件校对注记与 source-issues.md。词表不是解释所有当前用法的词典，疑点义项需另核词典或语法来源。国家 2020 完整词表和语法表位于 references/national-curriculum，来源、字段和哈希与上海书分开管理。

corpus_path=null（默认）表示使用当前安装版，不把安装绝对路径存进学情。旧档案若已有外部 corpus_path，可告知用户并经确认 configure 为 null；不静默修改其绑定。只有用户明确要使用另一个已校对副本才传 `--corpus` 并持久保存覆盖值。显式覆盖路径不可用时明确报错，不暗中换源；不做覆盖时无需任何额外 setup。

随附语料缺失或哈希变化是安装／资料完整性问题，不当作正常精简模式；先说明缺件，不能宣布“完整可用”。用户仍可选择临时做不依赖该资料的原创训练，明确未使用教材。更新语料须重走相关校对和封存，不能为通过检查临时改哈希。
